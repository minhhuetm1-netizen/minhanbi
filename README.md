# Business Analytics & Executive AI Dashboard

Ứng dụng Phân tích Doanh thu & Báo cáo Điều hành Kinh doanh Thông minh (BI Analytics & AI Executive Report).

## Hướng dẫn triển khai trên Vercel:
1. Đẩy toàn bộ các tệp trong thư mục này lên GitHub Repository của bạn.
2. Truy cập [vercel.com](https://vercel.com) -> New Project -> Import Repository.
3. (Tùy chọn) Trong mục **Environment Variables** trên Vercel:
   - Thêm Key: `GEMINI_API_KEY` | Value: `<Khóa API Gemini của bạn>`
4. Bấm **Deploy** để nhận link công khai.

## Chạy Localhost:
```bash
python server.py
```
Mở trình duyệt truy cập: `http://localhost:8080`
